# Lista-de-Compras
Plataforma criada durante a formação de JavaScript da Alura.
Neste projeto, foram utilizados conhecimentos de HTML, CSS e JavaScript.
O código HTML/CSS é disponibilizado inicialmente no curso, porém,
optei por criá-lo por conta própria. 
(Vale Destacar, que o projeto foi criado para telas mobile)

Durante o desenvolvimento deste projeto, pratiquei:

- Manipulação do DOM;
- Aplicação de EventListener;
- Funções JavaScript;
- Modularização;
- Importação e exportação de Módulos;
- Desenvolvimento HTML;
- Estilização CSS;
- Criação Mobile First.
